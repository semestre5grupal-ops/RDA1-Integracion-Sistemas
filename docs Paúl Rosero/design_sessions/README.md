# design_sessions/

This directory holds **design records** for features. Each feature should have a design document before implementation begins.

## Process

1. Run `$design-session <feature-name>` to start a new design.
2. The agent will create a file from `TEMPLATE.md` and guide you through the design.
3. Once the design is approved, run `$implementation-session <feature-name>`.
4. After implementation, the design document serves as documentation.

## Files

| File | Purpose |
|---|---|
| `TEMPLATE.md` | Template for creating new design sessions |
| `*.md` | Active or completed feature designs |
